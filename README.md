## Featured Project

### SakuKos — Smart & Tactile Expense Tracker
Aplikasi pelacak pengeluaran dan pengelolaan piutang/talangan (*split-bill*) berbasis *offline-first* yang dirancang untuk performa tinggi dan perlindungan data lokal.

- **Teknologi**: Flutter 3.x, Dart, Hive NoSQL, Impeller Rendering Engine.
- **Keamanan & Autentikasi**: Sistem keamanan hybrid PIN 6-digit (SHA-256) dan biometrik sidik jari dengan penanganan *race condition* siklus hidup aplikasi (*Android lifecycle state*).
- **Pengujian & Kualitas Kode**: 100/100 pengujian otomatis (*unit & widget tests*) berhasil dilewati, dengan 0 *warning/issue* pada `flutter analyze`.
- **Repositori**: [github.com/muhammadbusiri-021/sakukos-mobile](https://github.com/muhammadbusiri-021/sakukos-mobile)
- **Instalasi Mandiri**: [SakuKos v1.0.0 APK](https://github.com/muhammadbusiri-021/sakukos-mobile/releases/tag/v1.0.0)
