## 🌟 Proyek Unggulan (Featured Project)

### 📱 [SakuKos — Smart & Tactile Expense Tracker for College Students](https://github.com/muhammadbusiri-021/sakukos-mobile)
Aplikasi pencatatan keuangan dan manajemen talangan (*split-bill*) 100% *offline-first* yang dirancang khusus untuk mahasiswa dan anak kos.
* ⚡ **Tech Stack**: Flutter, Dart, Hive NoSQL, Impeller Vulkan Engine (120 FPS).
* 🛡️ **Keamanan**: Kunci Hybrid PIN 6-digit (enkripsi SHA-256) + Biometrik Sidik Jari (*anti-race condition*).
* 🧪 **Kualitas**: 100/100 Unit & Widget Tests Passed | 0 Issues `flutter analyze`.
* 📦 **Rilis Resmi**: [Unduh SakuKos v1.0.0 APK](https://github.com/muhammadbusiri-021/sakukos-mobile/releases/tag/v1.0.0)
